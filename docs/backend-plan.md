# 本機作品後台

已確認：本機版，沿用 Next.js；SQLite 和素材位於 data/，不上傳 GitHub。管理員由終端初始化，沒有公開註冊。首頁和作品頁只讀取已發布作品。

1. SQLite 作品／管理員／session／登入節流；第一次使用匯入六個 demo。
2. 登入、登出、受保護 CRUD、同源驗證、媒體檔案限制及 Range 讀取。
3. 後台表單、上傳、分區、排序、草稿與發布，前台改用資料庫。
4. 測試未登入拒絕、跨來源拒絕、登入失敗節流、CRUD、發布狀態、檔案拒絕、影片 Range、重啟持久化與建置。

需運行 Node 伺服器；out/ 是之前的靜態快照，不能執行後台。日後雲端部署需持久磁碟或改用雲端資料庫／物件儲存。
