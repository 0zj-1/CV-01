# Portfolio cover fonts

- The display face selects **Plang Expanded TRIAL ExtraBold** from the viewer's installed fonts with `local()`. No trial font files are copied into this website.
- The portable Latin fallback uses the existing Liberation Sans Bold asset in `public/pdfjs/standard_fonts/`, fitted to the same title width. Its license is already included with PDF.js standard fonts.
- PORTFOLIO stays in English for both language choices. Only the supporting text switches language, using the site's existing font stack.
